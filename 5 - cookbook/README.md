# Exercise 5: Cookbook
## Strategy: Procedural Decomposition & Sequences of Operations

This Go program reads a specified section of a text file, filters out punctuation and stop words, and prints the 25 most frequently used words. 

**Note:** It requires a `stop_words.txt` file located in the parent directory (`../`).

**Usage:** `go run main.go <file_path> <start_line> <end_line>`

For simplicity, I suggest you use the following command:
$ "go run main.go book.txt 28 13063"
